#Part 1: Introduction to Software Engineering

Explain what software engineering is and discuss its importance in the technology industry.
Software engineering is the systematic application of engineering principles to the design, development, testing, and maintenance of software.
Software engineering achieves high-quality secure products during delivery by implementing strict testing processes that validate product reliability.
Software engineering provides solutions to build expandable systems along with maintaining them by supporting clear documentation and modular code structure.


Identify and describe at least three key milestones in the evolution of software engineering.
1. 1968 – Software Engineering Concept: Coined at the NATO Conference to address the software crisis.  
2.1970s – Structured Programming: Introduced modular design for better maintainability.  
3. 2000s – Agile & DevOps: Enabled iterative development and continuous delivery.

List and briefly explain the phases of the Software Development Life Cycle.
1. Planning – Define project scope, objectives, and feasibility.  
2. Requirement Analysis – Gather and document user needs.  
3. Design – Create system architecture and technical specifications.  
4. Implementation – Write and integrate code.  
5. Testing – Identify and fix defects to ensure functionality.  
6. Deployment – Release the software for use.  
7. Maintenance – Provide updates and bug fixes post-release.

Compare and contrast the Waterfall and Agile methodologies. Provide examples of scenarios where each would be appropriate.
Waterfall is done after development while agile methodologies is ongoing throughout development.
Waterfall is best for projects with well-defined requirements, like banking systems.
Agile is ideal for dynamic projects, such as mobile app development.

Describe the roles and responsibilities of a Software Developer, a Quality Assurance Engineer, and a Project Manager in a software engineering team.
1. Software Developer
   -Writes, tests, and maintains code.
   -Implements software designs and fixes bugs.
2. Quality Assurance Engineer
   -Designs and executes test cases.
   -Identifies and reports bugs.
3. Project Manager
   -Plans, tracks, and oversees project progress.
   -Manages resources, risks, and deadlines.

Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.
1. Integrated Development Environments (IDEs)
  -Provide a unified platform for coding, debugging, and testing.
  -Example Visual Studio Code

2. Version Control Systems (VCS)
  -Track changes, enabling collaboration and rollback if needed.
  -Example github

What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.
1. Effective Team Collaboration
  -Hold regular meetings and encourage open communication.
2. Keeping Up with New Technologies
  -Participate in developer communities and conferences.
3. Debugging and Fixing Bugs
  -Conduct code reviews to catch issues early.
   
Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
1. Unit Testing - Tests individual components or functions.
                -Example: Testing a login function separately.
2. Integration Testing - Verifies interactions between integrated components.
                       -Example: Checking if the login module correctly interacts with the user database.
3. System Testing - Tests the entire software as a whole.
                  -Example: Running the full application to ensure all features work together.
4. Acceptance Testing - Ensures the software meets business needs and user expectations.
                      - Example: A client testing an e-commerce website before launch.

#Part 2: Introduction to AI and Prompt Engineering


Define prompt engineering and discuss its importance in interacting with AI models.
Prompt Engineering is the practice of designing and optimizing inputs/prompts to guide AI models in generating accurate and relevant responses.
-Improves AI Output – Well-structured prompts lead to precise and useful responses.
-Enhances Efficiency – Reduces trial-and-error when interacting with AI.

Vague Prompt-Tell me about technology.

Improved Prompt-Explain how artificial intelligence is transforming healthcare, focusing on diagnostics and patient care.

Why the Improved Prompt is More Effective?
More Specific – Focuses on AI’s role in healthcare rather than general technology.
